# Code of Conduct

This project is meant to be welcoming, especially to people setting up their first DNS filter.

## Our standard

- Be kind and patient. Questions that look basic to you may be someone's first step.
- Assume good intent, give constructive feedback, accept it gracefully.
- Keep discussions on topic and respect other people's time.
- Do not post private information (yours or others': IP addresses, account names, addresses).

Not acceptable: harassment, insults, discrimination, personal attacks, spam, or publishing other people's private data.

## Scope

Applies to all project spaces: issues, pull requests, discussions and comments.

## Enforcement

Maintainers may edit or remove contributions and may temporarily or permanently block people who violate this code.
To report a problem, use GitHub's **Report content** on the item, or open a
[private security advisory](https://github.com/JoKeks2023/adaptive-blocklist/security/advisories/new) titled
"Conduct report". Reports are handled confidentially.

This text is a short, plain-language code of conduct written for this project, inspired by common open-source community standards.
